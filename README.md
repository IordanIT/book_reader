# BookTalk — RAG-ассистент по книгам

## Быстрый старт

### 1. Установка зависимостей
```bash
pip install -r requirements.txt
```

### 2. Установка и настройка Ollama
```bash
# Установите Ollama: https://ollama.ai
# Скачайте модель:
ollama pull mistral
```

### 3. Добавьте книги
Поместите `.txt` файлы в `data/books/` (название файла = название книги).

### 4. Индексация книг
```bash
python src/index_books.py
```

### 5. Запуск чата
```bash
python src/chat.py
```
